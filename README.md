# Escropal brand assets

Public visual assets for Escropal interfaces. This repository does not contain the
Escropal application, authentication configuration, customer records or credentials.

## Files

- `exchange-gate.svg`: approved Escropal Exchange Gate mark, unchanged artwork.
- `inter-variable.woff2`: Inter 4.1 variable webfont from the official Inter project.
- `OFL.txt`: SIL Open Font License covering Inter only.

The Escropal name and logo are not licensed under the font's open-source licence.
Publishing the logo for display does not grant rights to impersonate Escropal.

## Font source

[Inter](https://rsms.me/inter/) by the Inter Project Authors.
Webfont source: https://rsms.me/inter/font-files/InterVariable.woff2?v=4.1
The font is distributed without modification. See OFL.txt for its licence.

## Hosting

Publish this repository with GitHub Pages, from the root of the main branch.
Use the HTTPS Pages asset URLs in the hosted login editor, not GitHub file-view URLs.
Verify successful responses and cross-origin font access before configuring login.
No custom domain, application deployment, tracking script or login form is included.
